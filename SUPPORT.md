# Support

## How to file issues and get help

This project uses GitHub Issues to track bugs and feature requests. Please search the existing issues
before filing new issues to avoid duplicates. For new issues, file your bug or feature request as a
new Issue.

This repository is a **demonstration sample** that accompanies an Azure Architecture Center article.
It is provided as-is and maintained on a best-effort basis. For help using it, open a GitHub Issue in
this repository.

## Microsoft Support Policy

Support for this sample is limited to the resources listed above.
